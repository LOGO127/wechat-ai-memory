# v0.3.8-alpha：精简体积，保留完整功能

本版聚焦 Windows 软件包瘦身，保留现有 UI、微信读取、高清图片恢复、本地语音转写和 PDF / Markdown / JSON 导出。

## 下载与升级

- **WeChatAIMemory-Portable.exe**：下载后双击运行，无需安装 Python。
- **WeChatAIMemory-Windows-x64.zip**：完整解压到新文件夹，再运行其中的 `WeChatAIMemory.exe`。不要覆盖解压到旧版目录，以免留下已移除的 DLL；也不要只复制 EXE。
- **SHA256SUMS.txt**：下载文件的 SHA-256 校验值。

升级前关闭旧版程序。导出文件和 `%LOCALAPPDATA%\WeChatAIMemory` 中的模型、转写缓存无需删除。

## 体积变化

以下是同一台 Windows x64 机器的本地构建对比；GitHub 构建的实际体积以附件为准，不包含首次使用时下载的 Whisper 模型。

| 项目 | v0.3.7 | v0.3.8 |
| --- | ---: | ---: |
| 便携 EXE | 210.3 MiB | 169.4 MiB |
| ZIP 下载包 | 216.2 MiB | 173.9 MiB |
| 解压目录 | 550.0 MiB | 439.0 MiB |

便携 EXE 减少约 **19.5%**，不是通过降低图片质量或删除语音功能实现。

## 改进

- WXGF 高清图片与语音共用 PyAV 编解码库，不再重复打包独立 FFmpeg。
- 移除未使用的 Qt 虚拟键盘、PDF 图片插件及其依赖，保留原生输入、SVG 图标和图形后备库。
- 隔离构建环境，防止其他开发工具的原生 DLL 混入软件包。
- 教学视频制作依赖改为开发者可选安装，不进入用户软件包。
- 发布流程新增体积预算及实际 EXE 的图片、音频和推理运行库检查。

## 验证范围

- 45 项源码测试通过。
- 本地目录版、便携版及实际 ZIP 解压版均完成启动、默认数据源、会话选择、关键词筛选和导出验收。
- 无损 WXGF 解码逐像素一致；图片导出保留 300 DPI 页面和原始附件。
- 实际打包程序通过 SILK 解码、音频重采样、CPU 推理运行库与 Silero VAD 推理检查；测试不下载模型、不读取真实聊天。
- GitHub Actions 从标签重新构建，并在通过源码测试与软件包验收后发布附件。

## 已知限制

仍为 Alpha 版本，尚未进行完整的 Windows 10/11 跨机器兼容性验收，也未进行 Windows 代码签名。微信升级可能改变内部数据格式；本轮组件测试不等同于所有真实语音的识别质量保证。

语音识别在本机执行，首次使用需要下载模型。本版仍包含语音引擎；“轻量主程序 + 按需安装语音组件”尚未实现。
