# 品牌指南

## 品牌符号

![微信 AI 记忆库品牌符号](../images/app-icon.png)

品牌符号由三个要素组成：

- 对话框：原始聊天是记忆的证据来源。
- 两条索引线：聊天内容可以被整理、筛选和检索。
- 金色记忆点：从连续对话中保留值得回看的信息。

符号采用独立设计，不使用微信官方双气泡标识，避免造成官方关联或授权的误解。

## 标准名称

- 中文：`微信 AI 记忆库`
- 英文：`WeChat AI Memory`
- 可执行文件：`WeChatAIMemory.exe`
- GitHub 仓库：`wechat-ai-memory`

对外说明应优先使用中文名称，英文名称用于文件名、版本资源和国际化场景。不要使用“微信官方”“微信授权”或其他可能造成隶属关系误解的表述。
